`template.config.ts` at the repository root holds the feature switches. Changes take effect after
the next deployment.

- `i18n.locales`: Languages of the site; the first one is the default
- `features.blog`: Show the blog
- `features.docs`: Show this documentation site
- `billing.refundWindowDays`: How far back refund requests can go
