## Why

试点当前只能通过服务器命令创建账号。用户要求创建 admin 管理员，并在界面中新增、配置团队账号，使后续成员交接不依赖开发者操作服务器。

## What Changes

- 增加独立于业务角色的服务端管理员权限，以及简洁的账号管理页。
- 支持新增账号、修改显示名称、工作区与角色、启停、生成随机重置密码。
- 创建 admin 及随机初始密码；密码只通过受保护的交付方式提供，不写入仓库。
- 控制库升级、版本冲突校验、会话撤销和管理审计；保留现有业务数据和权限边界。

## Capabilities

### New Capabilities
- `pilot-account-admin`: 管理员账号及受保护的团队账号管理。

### Modified Capabilities
无。

## Impact

控制库、认证上下文、管理员 API、CLI、前端导航与表单、契约及浏览器测试。无新增外部依赖；发布到既有独立 ECS 试点服务，不修改 d2market 或数据源配置。
