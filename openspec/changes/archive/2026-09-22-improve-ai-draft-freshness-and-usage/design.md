## Context
见 proposal.md。FastAPI 模块化单体、工作区隔离 SQLite、不可变 node_run 和逐尝试 Job/Attempt 已存在。当前草稿只在保存时计算 is_stale；生成解析失败早于 usage 提取。

## Goals / Non-Goals
读时状态与写时采用校验一致，失败用量可追溯。保留 18000 输出及 200000 总 token 等既有配置，不新增自动调用、自动业务决定或模型计价猜测。

## Decisions
1. 在候选聚合和任务读取边界投影实时草稿状态；保存快照不可变。基于同一输入指纹比较证据、标准、人审问题、复盘结果/批准依据；无法重建时保守标为不可采用，避免读取异常导致整页失败。
2. 草稿字段增量包含 is_stale、stale_reasons、current_input_hash、adoption_status。页面选择最新成功且可用稿；过期历史折叠展示，复制后材料变化须重新核对，不静默去掉来源后保存。
3. Provider 在内容/schema/引用检查前提取白名单 receipt，错误携带安全诊断；逐 attempt 保存，取消、过期及输出不可用也保留已知消费。不能接收时保持未知，历史缺 receipt 单独计数。
4. 工作区内提供模型用量列表、候选/项目过滤、按已知 token 和币种汇总及安全 CSV 导出。input_bytes 只代表输入规模，不能冒充 token。无原始提示词、响应或凭据进入诊断。
5. 使用已存在布局，业务第一屏不增加技术噪声，模型调用明细按需展开。

## Risks / Trade-offs
- 历史失败消费不可恢复 → 显示未记录，不生成虚构零值。
- 前端缓存与多标签页写入竞争 → 读取实时投影、刷新及采用时服务端最终校验。
- 各模型 usage 不一致 → 分别记录已知和未知，费用不擅自估算。

## Migration Plan
增量 JSON/API 字段，无 schema 迁移。离线回归、浏览器验收后停写备份并发布独立 ECS 服务；保留旧镜像回滚，真实工作区不写测试报价、结果或决策。
