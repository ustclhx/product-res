# Proposal

## Why

M2 能给出“值得关注”的商品簇，但团队真正决定跟卖前必须算清楚账：不同供应商、不同物流方案、同货源还是微改良，落地成本、保本价、毛利率和最晚决定日都不同。M3 让一条线索从发现走到决定并归档：录入报价、选择物流方案、在对比矩阵中选定组合、在待决定队列里按截止日处理，决定后进入选品档案库，30 天后回看实际结果。

## What Changes

- 供应商与报价：每个商品可挂多家供应商（链接、手填报价：单价、数量阶梯、MOQ、重量尺寸），报价可信度分“公开价 / 已确认报价”；供应商报价表可通过数据中心的文件导入批量录入。
- 物流方案：类型（eBay 直发 / 海外仓；Amazon FBA 头程 / FBM 直发）、时效、计费公式（首重续重、体积重系数、按方计费）、禁运属性。
- 成本参数：按平台与类目的佣金费率、固定费、广告费率、退货预留比例、汇率来源；Amazon 仓储费、入库配置费；FBA 配送费优先取 SP-API 预估，失败时用费率表。
- 核算（`packages/costing`，纯函数）：落地成本、保本价、竞品中位价下的毛利率、最晚决定日；对比矩阵 = 供应商 × 物流方案 × 跟卖方式；成本瀑布（采购 → 头程 → 平台费 → 配送/尾程 → 广告 → 退货预留 → 净利润）。
- 待决定队列（工作台首页）：核算完成的线索按最晚决定日排序，7 天内标橙、已过标红；跟卖（首批数量、目标售价、计划上架日）或放弃（原因枚举）。
- 选品档案库：保存决定当时的分数、核算组合、权重版本与数据快照引用；30 天后提醒回看，录入实际销量和售价并与当初判断对比。
- M2 的利润空间与供应时效维度改用核算结果；置信度加入“成本确定性”。

## Capabilities

### New Capabilities

- `supplier-quotes`：供应商、报价阶梯、可信度、导入。
- `logistics-costs`：物流方案、成本参数、费用预估来源。
- `costing-matrix`：落地成本、保本价、毛利率、对比矩阵与成本瀑布。
- `decision-queue`：待决定队列、跟卖与放弃决定。
- `selection-archive`：选品档案库与 30 天回看。

### Modified Capabilities

- `selection-scoring`（来自 add-follow-selection）：利润空间、供应与时效维度使用核算结果；置信度加入成本确定性。

## Impact

- 新增 `packages/costing`（纯函数，依赖 shared）。
- 新增空间级表：`supplier`、`supplier_quote`、`logistics_profile`、`cost_param`、`costing_scenario`、`decision`、`follow_outcome`。
- `apps/web`：线索详情的核算页、工作台首页待决定队列、选品档案库页面、设置页的物流方案与成本参数标签。
- `apps/jobs`：30 天回看提醒（站内通知，复用模板 notifications）。
- 依赖 `add-follow-selection` 的线索表。
