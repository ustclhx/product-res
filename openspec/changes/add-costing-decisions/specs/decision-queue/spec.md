# Spec Delta

## Purpose

在工作台首页按截止日处理待决定线索。

## ADDED Requirements

### Requirement: 待决定队列
工作台首页 SHALL 显示已选定核算组合、尚未决定的线索，按最晚决定日升序；7 天内标橙，已过期标红。

#### Scenario: 临近截止
- **WHEN** 线索最晚决定日在 5 天后
- **THEN** 队列中该行标橙

### Requirement: 跟卖与放弃
团队 SHALL 能对线索作出跟卖（首批数量、目标售价、计划上架日）或放弃（利润不够 / 竞争太多 / 时间来不及 / 货源不行 / 侵权风险 / 其他 + 说明）的决定。决定 MUST 保存当时的分数、权重版本、所选组合与数据引用，决定后线索不可再修改核算。

#### Scenario: 放弃
- **WHEN** 团队以“竞争太多”放弃线索
- **THEN** 线索状态为已放弃，进入选品档案库并显示原因
