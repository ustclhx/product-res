# Spec Delta

## Purpose

计算落地成本、保本价、毛利率并在对比矩阵中选定组合。

## ADDED Requirements

### Requirement: 核算
系统 SHALL 为 供应商报价 × 物流方案 × 跟卖方式 的每个组合计算落地成本、平台费、配送/尾程、仓储、广告、退货预留、净利润、保本价、竞品中位价下的毛利率和最晚决定日。任一必需输入缺失时 MUST 显示缺少的输入而不计算，MUST NOT 用 0 代替。

#### Scenario: 缺少重量
- **WHEN** 报价没有重量
- **THEN** 依赖重量的物流组合显示“缺少：重量”，不给毛利率

#### Scenario: 保本价
- **WHEN** 佣金率 15%、广告率 5%、退货预留 3%、固定费 $0.30、落地成本 $8.00
- **THEN** 保本价为 (8.00 + 0.30) ÷ (1 − 0.23) ≈ $10.78

### Requirement: 对比矩阵与成本瀑布
对比矩阵 SHALL 高亮毛利率最高且来得及的组合；团队选定一个组合后线索进入待决定队列。所选组合 SHALL 以成本瀑布展示采购 → 头程 → 平台费 → 配送/尾程 → 广告 → 退货预留 → 净利润。

#### Scenario: 来不及的组合
- **WHEN** 某物流方案使最晚决定日早于今天
- **THEN** 该组合标为“来不及”，不作为最优组合
