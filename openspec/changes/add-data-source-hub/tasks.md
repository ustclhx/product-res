# Tasks

依赖 `bootstrap-selection-workbench` 完成。所有完成勾选都须有验证证据。

## 1. 契约与注册表

- [ ] 1.1 在 `packages/datasources` 定义 DataKind、BudgetSpec、SourceConnector、ConnectorContext、ProbeReceipt（design D1），提供 HTTP 基础（超时、响应体上限、错误分类、日志脱敏）。验证：错误分类与脱敏的单元测试；`check:deps` 通过。
- [ ] 1.2 实现注册表与 `data_sources` 表（启用、非敏感配置、最近回执），凭据从 secret 文件读取。验证：按能力派发、停用不派发、凭据不出现在数据库与日志的测试。
- [ ] 1.3 实现模拟连接器（可配置延迟、失败、额度耗尽、凭据失效、字段缺失）。验证：仅在测试与开发环境注册。

## 2. 额度账本

- [ ] 2.1 `source_budgets` / `budget_ledger` 与 reserve / settle / release（design D3）。验证：真实 Postgres 下两 jobs 并发预扣不超限；安全线、硬上限、人工刷新三种场景测试。
- [ ] 2.2 悬挂预扣对账、外部剩余额度对账与暂停、月度预算日分配与滚动。验证：对应 spec 场景的测试。

## 3. 同步编排与存档

- [ ] 3.1 每个数据源一个队列，按连接器声明配置并发与速率；`sync_schedules` / `sync_runs`；不可重试错误（凭据失效、额度耗尽）停止当日任务。验证：一个数据源积压不影响其他队列的测试。
- [ ] 3.2 每日流水线（Scheduler `Asia/Singapore` 02:00、`missedRun: 'once'`，Workflow 串联步骤）。验证：中途重启不重复已成功步骤的外部调用；停机多天只补一次。
- [ ] 3.3 原始响应存档到对象存储（key 规则、哈希、保留期清理）与回放。验证：回放不产生账本消耗；超过保留期后观测值保留。
- [ ] 3.4 人工刷新接口（显示预计花费，遵守额度）。验证：刷新到硬上限被拒的测试。

## 4. 统一数据模型

- [ ] 4.1 `marketplace_products`、`sellers`、`keywords`、`reviews`、`fee_estimates`、`observations`（按月分区）、`metric_priorities` 迁移与 `scoped()` 访问。验证：迁移由 migrator 执行；跨空间隔离测试。
- [ ] 4.2 指标枚举与单位；幂等写入；主值选择与离散度；缺失与零的区分。验证：spec 中多来源主值、修改优先级、缺失不补零场景测试。

- [ ] 5.2 列名识别、手动映射、模板保存复用、单位币种确认、预览校验、跳过错误行。验证：空单元格不补零；模板复用测试。
