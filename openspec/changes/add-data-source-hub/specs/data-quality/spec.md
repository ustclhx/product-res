# Spec Delta

## Purpose

定义同步后的数据质量检查，让问题数据在进入算法前被发现。

## ADDED Requirements

### Requirement: 自动质量检查
每次同步运行结束后，系统 SHALL 检查：关键字段缺失率、相对前一日的异常跳变、同一指标来源间差异、各方向数据新鲜度、同步失败。检查阈值 SHALL 可配置，默认缺失率 > 20%、跳变 > 3 倍、来源差异 > 50%、新鲜度 > 36 小时。

#### Scenario: 来源差异过大
- **WHEN** 同一商品同一天两个来源的月销量估算分别为 300 和 900
- **THEN** 生成一条“来源差异”问题，列出两个来源和数值

#### Scenario: 数据过期
- **WHEN** 某方向最近一次成功同步已超过 36 小时
- **THEN** 生成一条“新鲜度”问题并在工作台提示

### Requirement: 问题列表与状态
质量问题 SHALL 汇总展示类型、涉及实体、指标、详情、首次与最近出现时间，并支持标记为“已知/忽略”。同一问题重复出现 MUST 合并为一条并更新最近出现时间，而不是重复生成。

#### Scenario: 重复出现
- **WHEN** 同一商品连续三天出现同一跳变问题
- **THEN** 问题列表中只有一条，最近出现时间为第三天
