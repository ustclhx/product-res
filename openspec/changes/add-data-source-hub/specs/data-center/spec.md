# Spec Delta

## Purpose

定义数据中心页面，让团队查看数据源状态、同步情况、数据内容、导入和质量问题。

## ADDED Requirements

### Requirement: 数据中心总览
数据中心 SHALL 显示已启用数据源数、记录总数、今日同步次数和今日额度/费用使用，并为每个数据源显示卡片：凭据与核验状态、提供的数据类型、记录数、同步频率、最近一次同步时间与结果、当前周期额度进度。

#### Scenario: 额度进度
- **WHEN** eBay Browse 当日已消耗 1200 次
- **THEN** 其卡片显示 1200 / 4500（安全线）和硬上限 5000

### Requirement: 数据源配置
团队 SHALL 能在数据中心启用或停用数据源、调整同步频率、额度安全线（不超过硬上限）和指标来源优先级，并触发核验。修改 MUST 只影响之后的同步。

#### Scenario: 安全线不可超过硬上限
- **WHEN** 把 eBay Browse 的安全线设为 6000
- **THEN** 保存被拒绝，提示不能超过硬上限 5000

### Requirement: 数据预览
团队 SHALL 能按数据源和数据类型预览最近数据，提供 JSON、表格、Schema、原始响应四种视图；原始视图 MUST 不包含凭据。

#### Scenario: 切换视图
- **WHEN** 选择某数据源的商品快照并切换到 Schema 视图
- **THEN** 显示归一化后的字段、类型、单位和来源说明

### Requirement: 同步记录、导入与质量问题入口
数据中心 SHALL 提供同步记录（可筛选失败、可重新入队）、文件导入向导和数据质量问题列表。

#### Scenario: 重新入队
- **WHEN** 在同步记录中对一条失败任务点击“重新入队”
- **THEN** 任务按额度规则重新执行，结果出现在新的运行记录中
