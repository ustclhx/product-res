# Spec Delta

## Purpose

按平台、方向和信号类型衡量算法是否可信。

## ADDED Requirements

### Requirement: 准备度等级
系统 SHALL 按 平台 × 方向 × 信号类型 统计有效样本数与命中率 Wilson 下界，并与基线比较得到等级：冷启动（< 20）、观察期（20–50，置信度上限为中）、可用（≥ 50 且下界 ≥ 基线）、可信（≥ 100、权重已校准、最近 3 个月稳定）。回放与导入样本按配置的较低权重计入有效样本。

#### Scenario: 从冷启动进入观察期
- **WHEN** 某 eBay 方向的有效样本从 19 增加到 20
- **THEN** 准备度变为观察期，该方向线索开始显示等级，置信度上限为中

### Requirement: 历史命中率置信度
线索置信度 SHALL 加入同平台、同方向、同信号类型的历史命中率（Wilson 下界）；样本不足时该项为空并降低总置信度。

#### Scenario: 无样本
- **WHEN** 该组合没有任何已打标签的样本
- **THEN** 历史命中率显示“无样本”，不按 0 计
