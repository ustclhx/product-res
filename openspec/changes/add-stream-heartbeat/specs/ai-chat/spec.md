## ADDED Requirements

### Requirement: 流式空闲心跳
对话流式回复 SHALL 在等待首个上游 token 前发出响应头与起始片段；此后任意片段之后静默达到心跳间隔（默认 25 秒）时，系统 MUST 发送前端忽略、不进入消息内容的保活片段，有真实输出时重新计时。流结束、失败或客户端断开后 MUST NOT 残留心跳定时器。心跳 MUST NOT 改变预扣、检查点与结算。

#### Scenario: 隐藏推理超过间隔
- **WHEN** 推理模型在 reasoning 不展示时连续超过一个心跳间隔没有正文
- **THEN** 每个间隔收到一个保活片段，最终消息只包含正文，结算与无心跳时一致

#### Scenario: 真实输出重置计时
- **WHEN** 静默期间到达一段正文
- **THEN** 下一个保活片段从该正文起满一个间隔才发送

#### Scenario: 回复结束或断开
- **WHEN** 回复完成、失败或客户端断开
- **THEN** 不再发送保活片段，也不残留定时器
