# Spec Delta

## Purpose

定义卖家精灵开放平台连接器提供的选品、市场、关键词和评论相关数据。

## ADDED Requirements

### Requirement: 选产品与选市场
系统 SHALL 支持按方向调用选产品（销量增长、评论增长等条件）和选市场接口，结果中的商品加入跟踪候选，市场指标保存为类目或关键词维度的观测。

#### Scenario: 选产品结果
- **WHEN** 按方向条件调用选产品
- **THEN** 返回的 ASIN 及其销量估算、评论增长被保存，来源为卖家精灵

### Requirement: 关键词与反查流量词
系统 SHALL 获取关键词的站内搜索量、趋势，以及指定 ASIN 的反查流量词。

#### Scenario: 反查流量词
- **WHEN** 对一个线索商品请求反查流量词
- **THEN** 保存该 ASIN 的关键词列表及各词搜索量

### Requirement: 评论能力核验
系统 SHALL 核验评论增长与评论正文是否可得；只有核验通过才声明评论能力。

#### Scenario: 只有评论数
- **WHEN** 核验发现只返回评论数而无正文
- **THEN** 该数据源只提供评论数观测，不声明评论正文能力

### Requirement: 合同额度与并发
卖家精灵的预算与并发 SHALL 按合同配置；超出并发的请求 MUST 排队而不是失败。

#### Scenario: 并发上限
- **WHEN** 合同并发为 2，同时有 5 个任务
- **THEN** 同时最多 2 个请求在途，其余排队
