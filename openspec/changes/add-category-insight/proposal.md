# Proposal

## Why

除了跟卖，团队还要判断“一个品类值不值得做、怎么做出差异”（品牌选品）。这主要服务 Amazon，需要把搜索量趋势、新品数、价格带、头部集中度、竞品矩阵和差评痛点放在一份可刷新的研究报告里，并能把其中的商品直接转为跟卖线索（默认同款微改良）。

## What Changes

- 品类研究：按 平台站点 + 类目或关键词集合 创建研究，生成报告快照，可随时用最新数据刷新，历史快照保留。
- 报告模块：品类概览（搜索量同比、近 90 天新品数、价格带分布、头部集中度）、12 个月趋势（搜索量与销量估算月度曲线，标注节点）、竞品矩阵（头部 N 个商品的价格、评分、评论数、销量估算、价格 × 销量气泡图）、差评痛点（词云与主题占比）、退货率（只展示能拿到的数据，拿不到显示“无数据来源”）、差异化建议（AI，引用具体评论和竞品）。
- 报告中的商品一键转为线索，默认跟卖方式“同款微改良”，改良点带入核算。
- 报告归档到选品档案库。

## Capabilities

### New Capabilities

- `category-insight`：品类研究、报告快照与刷新、各模块计算、AI 差异化建议、转线索。

### Modified Capabilities

无。

## Impact

- 新增 `packages/insight`（聚合纯函数：价格带、集中度、同比、新品数、痛点归类输入整理）。
- 新增空间级表 `category_study`、`category_study_snapshot`；评论数据需要新增 `marketplace_review`（部署级）与指标。
- `apps/web`：`/app/$slug/category` 页面与报告详情；AI 建议走 `packages/ai` 的模型与用量预算。
- 评论来源尚未确定（需要核验哪个数据源能提供评论正文），未确定前差评痛点与差异化建议显示“无数据来源”。
