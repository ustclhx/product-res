# Design

## 决策

### D1 表

- `category_study`（空间级）：名称、平台站点、类目 ID 列表、关键词列表、头部 N（默认 20）、状态。
- `category_study_snapshot`（空间级）：研究 × 生成时间：各模块结果 JSON（含每个数值的来源引用）、数据截止日期。只追加，报告页默认显示最新快照。
- `marketplace_review`（部署级）：商品 × 评论 ID：评分、标题、正文、日期、来源。由能提供评论的连接器或导入写入。

### D2 计算（`packages/insight`）

- 搜索量同比：关键词 `search_volume_monthly` 最近 12 个月合计 ÷ 前 12 个月合计 − 1；任一月缺失则只用双方都有的月份，并标注覆盖月数。
- 近 90 天新品数：类目内 `listed_at`（或首次发现时间）在 90 天内的商品数，注明口径。
- 价格带：主值价格分 6 档（按分位自动或团队自定义边界），每档商品数与销量估算占比。
- 头部集中度：销量估算前 N 名占比（CR3 / CR10），只有单一来源时标“未交叉验证”。
- 竞品矩阵：头部 N 个商品的主值与来源；气泡图 x=价格、y=月销量估算、大小=评论数。
- 差评痛点：评分 ≤ 3 的评论，按 AI 归纳主题（每个主题附代表评论 ID），没有评论数据时整个模块为“无数据来源”。
- 差异化建议：输入痛点主题 + 竞品卖点（标题/要点），AI 生成 3–5 条建议，每条必须引用至少一条评论或竞品 ID；未配置 AI 模型时模块显示“AI 未配置”。

### D3 刷新与成本

刷新只读已有观测值，不主动触发外部采集；需要补数据时提示到数据中心人工刷新（遵守额度）。AI 调用计入 `packages/ai` 用量。

### D4 页面

- `/app/$slug/category`：研究列表与新建。
- `/app/$slug/category/$studyId`：报告（对照设计稿“品牌选品 · 品类洞察”），模块卡片 + ECharts（折线、气泡、词云、柱状），快照切换，刷新按钮，转线索。

## 风险与取舍

- 评论来源未定（卖家精灵 / Jungle Scout / 导入），这是报告中最依赖外部的部分。
- 销量估算各工具差异大，所有聚合都显示来源与离散度。
