# file-storage Specification

## Purpose

管理空间内的文件（用户上传的素材与 AI 产出）：上传流程、访问控制、存储配额与清理，保证文件只能被有权限的人访问且配额不可被绕过。

## Requirements

### Requirement: 上传前声明与限制
上传文件前，客户端 SHALL 声明文件类型与大小；类型不在白名单、单文件超过上限或会超出空间存储配额时，系统 MUST 拒绝签发上传地址。

#### Scenario: 超出配额
- **WHEN** 空间配额 5 GB、已用 4.9 GB，声明上传 200 MB 文件
- **THEN** 请求被拒绝并提示配额不足

### Requirement: 上传后确认真实文件
上传完成后，系统 SHALL 以存储中的实际文件大小与类型为准再次校验；与声明不符或超出配额时 MUST 删除该文件并拒绝；只有确认通过的文件 SHALL 能被引用（如作为生成任务的输入）。

#### Scenario: 实际大小超过声明
- **WHEN** 客户端声明 1 MB，实际上传了 50 MB
- **THEN** 确认失败，文件被删除，不计入配额

#### Scenario: 引用未确认的文件
- **WHEN** 提交生成任务时引用一个尚未确认的文件
- **THEN** 任务提交被拒绝

### Requirement: 未确认上传的清理
签发上传地址后超过 1 小时仍未确认的文件 SHALL 被清理，不计入配额。

#### Scenario: 上传中途放弃
- **WHEN** 用户拿到上传地址但没有完成确认，1 小时后清理任务运行
- **THEN** 该文件记录与存储对象被删除

### Requirement: 访问控制
文件 MUST 只能被所属空间的成员访问；访问时系统 SHALL 校验权限后签发短期有效的下载地址，存储桶本身 MUST NOT 公开。

#### Scenario: 非成员访问
- **WHEN** 非该空间成员请求文件
- **THEN** 返回 404

#### Scenario: 下载地址过期
- **WHEN** 签发的下载地址超过有效期后被使用
- **THEN** 访问被拒绝

### Requirement: 可选的公开分享
文件所有者 SHALL 能为单个文件生成公开分享链接并随时撤销；撤销后该链接 MUST 立即失效。

#### Scenario: 撤销分享
- **WHEN** 用户撤销一个文件的分享链接后，他人访问该链接
- **THEN** 返回 404

### Requirement: 存储配额
空间已用存储 SHALL 等于所有已确认且未删除文件的大小之和，并 MUST NOT 超过其权益规定的配额（AI 产出转存同样计入）；超出时新的上传与生成 SHALL 被拒绝。

#### Scenario: 配额已满时生成
- **WHEN** 空间存储已满时提交图片生成
- **THEN** 请求被拒绝并提示清理文件或升级

### Requirement: Node 通用 S3 配置
Node 文件存储 SHALL 默认接入外部 S3 兼容服务，允许部署管理员配置 endpoint、region、bucket 和 path-style。预签名上传与下载 URL MUST 使用配置的访问端点，不得固定服务商域名。完整启用配置 MUST 在启动时校验，错误仅报告变量名；未配置存储时公开页面仍可运行，文件副作用前 MUST 明确拒绝。

#### Scenario: 更换外部服务
- **WHEN** 管理员将 R2 S3 API 配置替换为另一个有效 S3 兼容 endpoint、region、bucket 及 path-style 并重启
- **THEN** 上传、确认、下载和删除使用新存储，业务接口与租户授权不变，签名 URL 指向新端点

#### Scenario: 未配置与不完整配置
- **WHEN** Node 未配置任何存储参数，或只配置部分必需参数
- **THEN** 前者保持文件能力不可用并在写记录前拒绝文件操作；后者启动失败并列出缺失变量名，均不输出凭据

### Requirement: Node 文件操作一致性
配置完整的 Node 目标 SHALL 提供文件上传、确认、授权下载、撤销分享和清理能力。上传签名 SHALL 有效 10 分钟，下载签名 SHALL 有效 5 分钟；上传 MUST 绑定声明 MIME 并禁止覆盖同 key 对象。确认 MUST 使用真实大小与 MIME，删除失败 MUST 保留可重试记录。空间权限、配额与未确认文件限制 MUST 与 Cloudflare 一致。

#### Scenario: 实际对象不符合声明
- **WHEN** 已签发 Node 上传 URL 的对象大小或 MIME 不符合声明
- **THEN** 确认失败，不增加已用配额，删除对象；删除失败时保留失败清理线索

#### Scenario: 重用上传地址覆盖文件
- **WHEN** 客户端使用同一个尚未过期的 PUT 签名再次写入已存在 key
- **THEN** 存储拒绝覆盖，原文件内容不变

#### Scenario: 私有下载与清理
- **WHEN** 非空间成员请求私有文件，或文件成为超过 1 小时的未确认上传
- **THEN** 前者返回 404；后者由已装配的 Node 清理任务删除，失败可重试；存储桶不公开

### Requirement: Node 安全媒体转存能力
Node 存储 SHALL 提供供媒体工作流复用的安全转存能力：只下载白名单 HTTPS 来源，禁止重定向，校验 MIME，按实际流字节限制大小。失败 MUST 释放源流、终止未完成上传并清理残留；返回实际存储的大小和 MIME。重放同一产出 MUST 复用确定性 key 与既有持久记录，不重复计入配额。

#### Scenario: 不可信或超限来源
- **WHEN** 产出地址重定向到其他主机，来源不在白名单，或实际下载字节超过限额
- **THEN** 转存拒绝，不产生可引用的已确认文件，流和未完成分片被释放/清理，失败可由调用方处理

#### Scenario: 持久化重放
- **WHEN** 产出已成功存储而调用方重放同一持久化操作
- **THEN** 对象与文件身份保持不变，空间配额仅计算一次

### Requirement: 可选自带对象存储
Compose SHALL 提供默认关闭的自带 S3 兼容存储 profile；关闭时 MUST 不启动该服务或要求其凭据。启用时 SHALL 使用私有桶和持久数据卷，并有非 root 运行、健康检查、资源限制与滚动日志。S3 API SHALL 经受控代理 80/443 供客户端访问，管理接口与内部端口 MUST 不映射公网；代理 MUST 保持签名所需 Host、路径和查询。

#### Scenario: 外部存储默认部署
- **WHEN** 未启用自带对象存储 profile，且应用配置了外部 S3
- **THEN** Compose 不启动自带存储，上传与下载无需自带存储的地址、卷或密钥

#### Scenario: 自带存储浏览器上传
- **WHEN** 开启 profile，客户端从公开 HTTPS 存储地址取得预签名 URL 并执行允许来源的 CORS PUT/GET
- **THEN** 上传、HEAD 确认与下载成功，私有桶匿名读取失败，重启后已存对象仍在，签名没有使用容器内网域名

### Requirement: 文件与媒体能力分别启用
Node 文件存储配置成功后 SHALL 解除文件能力不可用限制并支持文件清理。媒体提交 MUST 仍同时要求存储与工作流可用；仅交付存储 MUST NOT 被视为媒体工作流已可用，拒绝必须发生在任务创建和积分预扣前。

#### Scenario: C 已装配但 B 媒体移植未完成
- **WHEN** Node 有可用存储但没有已装配的媒体工作流
- **THEN** 文件上传/确认/下载可用，媒体提交仍返回能力不可用，且不创建任务或预扣积分
