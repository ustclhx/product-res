# 车辆内饰收纳试点切片指南

更新：2026-09-21。本文是本轮团队试用的业务工作指南，不是市场结论、供应商名录或经营预测。

## 本轮范围

本轮明确研究“车辆内饰”方向，首个窄切片建议从车内座椅背收纳（例如 seat back organizer）开始。它只是便于团队建立可比较样本的研究切片，不代表已经验证存在商机，也不代表应当采购、上架或投放。若首轮材料显示该切片不适合，决策负责人可以退回补证、继续观察或改选同一方向内的其他切片，并保留原有记录。

渠道和市场固定为 Amazon US 与 Google Shopping US，查询使用英语和美国口径。Amazon 线索可由 DataForSEO Amazon US 返回，Google Shopping 线索可由 SerpApi Google Shopping US 返回；来源是否可用、是否授权，以登录后的来源状态和现场记录为准。来源不可用时，使用手工添加或 CSV 导入，并记录原因，不把代码可用写成真实查询已完成。

## 每款候选的可比较字段

先记录观察到的事实，再记录估算、假设和待补证项。建议每款至少建立以下字段：

| 比较组 | 字段 | 记录要求 |
| --- | --- | --- |
| 款式 | 款式类别、主要功能、分隔/口袋布局、是否带平板位或保温位、是否可折叠 | 用页面可见描述和图片定位；不能把宣传词当成已验证性能 |
| 适配车型 | 适配声明、座椅类型、前排/后排位置、儿童座椅或中央扶手冲突、已知不适配车型 | 记录商品原文、变体和未知项；没有车型清单就写未提供 |
| 安装方式 | 绑带、扣具、挂钩、绕杆/头枕固定等；安装步骤和可调范围 | 记录页面说明或人工核验来源；不要把“通用”直接当作所有车型适配 |
| 尺寸材料 | 长宽高、收纳容量或可用空间、重量、面料/板材/内衬、清洁方式 | 单位统一为原始单位并在比较时换算；缺失保持空值 |
| 数量 | 单件/套装件数、销售包装数量、可用库存或页面数量标签（若返回） | 标明是每件、每套还是页面标签；未知不填 0 |
| 价格 | 标价、币种、变体、优惠券或促销、运费和税是否已知、观察时间 | 标价与到手价分开；未知运费/税不填 0 |
| 需求/竞争线索 | 评分、评论数、搜索位置、赞助标记、页面购买量标签（若返回） | 这些是市场观察线索；不写成团队订单或完整销量 |
| 供给 | MOQ、采购单价、计价单位、币种、报价有效期、供应商来源、运费/履约费 | 只接受报价单、询价或人工录入等供应商材料；市场页面不能替代报价 |
| 证据 | 来源类型、来源名称、稳定链接/文件名、外部 ID 或文件行号、采集/报价时间、变体、核验状态、操作者和备注 | 市场观察、供应商报价、人工核验分别定位；缺失、过期和冲突要显式标记 |

同一产品的不同颜色、尺寸、套装数量或车型版本要分别记录外部 ID、变体和价格口径；不能把一个变体的尺寸、价格或适配声明套到另一个变体。供应报价表和市场观察表分开保存、分开核验，必要时在候选评估中通过来源定位关联。

## 证据、待补证和人工决策

按以下顺序推进，每一步都保留历史版本：

1. **建立项目标准。** 分析负责人创建 Amazon US / Google Shopping US 项目，写明车内收纳切片、目标用户、禁限约束、必填字段、成本口径、截止时间和验证条件，由决策负责人确认。阈值是本轮团队标准，不是系统或 AI 给出的市场结论。
2. **保存市场观察。** 记录 q、来源、站点、地点、语言、采集时间、前 10 条顺序、商品链接/外部 ID、变体、价格及需求/竞争线索。把未核验、过期、冲突或缺失字段标清，不能用 AI 补空值。
3. **单独补供应证据。** 对进入研究的候选建立报价/询价任务，补 MOQ、采购单价、计价单位、报价有效期、供应商来源、运费和履约成本。等待材料时写“待供应商补证”，不把市场标价当采购成本，不把未知当零。
4. **人工评估。** AI 草稿只能整理已保存证据。分析负责人逐项修正引用，补未知、反证、假设和币种/窗口，保存人工评估版本。关键费用缺失时可以继续研究，但不能声称利润可比或已具备采购依据。
5. **人工决策。** 决策负责人基于当前标准和核验证据选择批准验证、退回补证、继续观察或否决，并写理由。初筛通过不等于批准验证；任何恢复或例外都要说明原因。
6. **受控验证与复盘。** 批准后建立询价、样品或小测任务，指定负责人、期限、完成条件和实际结果。完成任务不等于商品成功。上市后结果标 REAL，联调标 TEST，示例标 DEMO；未上市写原因，未知经营字段留空。复盘建议由决策负责人确认后才形成下一轮标准。

## 试用入口与访问方式

本轮受控试用入口为 `http://127.0.0.1:18081`。管理员可在自己的电脑建立隧道：

```sh
ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:18081:127.0.0.1:18081 root@43.106.17.72
```

保持终端连接，再打开上述地址。该 root 命令仅供已有管理权限的操作者使用；团队成员由管理员分配各自受限 SSH 访问。它是 loopback 入口，不是团队可直接共享的公开网址；团队成员通过管理员管理的 SSH 访问进入，按个人账号和已分配工作区使用。不要共享 root、服务器口令或服务端 secret，也不要让全员使用同一个 SSH 身份。账号、端口转发和撤销由管理员按团队成员变更管理。

后续将配置现有 Cloudflare 子域名作为团队 HTTPS 入口；域名尚未配置不阻碍本轮受控试用。入口准备好后仍以登录后的工作区、来源状态和现场记录为准。

NewAPI 的可用性和模型切换单独记录。DeepSeek 官方渠道切换和生成校验由管理员记录，实际启用状态见现场部署记录。没有该记录时，仍可用市场来源（若已授权）以及人工/CSV 流程推进，不把测试回执当真实业务证据。
