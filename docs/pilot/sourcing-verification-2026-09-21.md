# 补证工作台验证（2026-09-21）

## 功能与边界

- 候选页先展示本阶段核心材料、质量、任务责任人与期限；AI、原始证据、历史与正式初筛详情折叠。
- 报价、售价、车型适配采用专用表单，支持线下厂商、联系方式、货号、套装数量、MOQ、交期、税运费和来源日期。
- 记录修订保留历史；价格口径变化撤回已失效旧证据；车辆配置变化撤回旧实车适配结果。
- OEM 研究/打样/上市是材料准备阶段，不自动改正式标准、批准采购或完成任务。
- 研究参考材料任务可以由负责人确认收集完成，证据仍保留未核验或估算状态。
- 国内来源只进行受支持商品 URL 的平台/商品编号识别，无网络抓取。1688/义乌购需官方授权并确认接口字段后另行实现真实详情适配器。
