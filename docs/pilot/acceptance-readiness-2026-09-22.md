# 试点开发交付与验收准备

对应变更：`complete-pilot-acceptance-readiness`。真实业务验收仍遵循 [验收指南](acceptance-guide-2026-09-22.md)，不把工程用例或研究回流算作真实经营验证。

## 本轮能力

- 候选页新增“研究结论与反馈”：决策负责人记录停止/暂缓、原因、证据及启示；分析负责人提出规则/必需材料/研究启示建议；负责人确认后可创建下一项目。初始规则允许为空，但必需材料至少一项。历史标准、批准和经营结果保持不变。
- 工作台分别显示研究回流与经营闭环。候选自身的市场批次、人工链接或供应商记录可构成来源；关联竞品不构成自身事实。
- 采购表单支持样品/现货/定制 MOQ、同数量单位的价格阶梯、共享原件链接；主报价不自动变成最低阶梯价格。
- 新的已核验实车通过必须包含明确样品、左右前排检查和目标一致性；通用证据入口也不能绕过。
- 市场入口显示剩余请求、查询范围、观察时间；历史复用不计新请求。新查询明确提示可能计费，市场新观察不会替代人工核验证据。
- DataForSEO 结果未知时可输入官方 task ID，服务端仅用官方固定读取接口核对取回；保留原尝试、配额及费用。只支持可唯一核对的近期原任务，不能恢复则保留未知并显示说明。SerpApi 先人工核对供应商记录，需新查询时显式提交；未知结果均不自动重发。
- 新增 `scripts/pilot_tunnel.py`：启动、状态、重启、停止，保留其他进程。健康失败与 SSH 连接失败分别提示。

## 工程验证

- 完整 `make check`：195 个后端测试、5 个前端单元测试通过；Ruff、Mypy、ESLint、TypeScript、前端构建和契约一致性通过。
- Demo 浏览器回归：2 项通过。
- 试点浏览器：7 个不同场景最终均通过（全套中 5 项通过，更新旧统计文案断言后原闭环与隔离 2 项定向通过）；无 API 兜底跳过页面操作。
- 桌面/手机检查：研究结论、报价明细均可操作，低频细节折叠；截图保存在本机 /private/tmp/product-res-research-{desktop,mobile}.png 和 product-res-sourcing-{desktop,mobile}.png。
- 独立审查发现并补回归：空必需材料绕过、通用实车证据绕过、刷新替代核验证据、件/套阶梯重叠。Impeccable 针对本轮页面的机械检查未发现问题。
