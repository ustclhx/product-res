# 账号管理

试点管理员在登录后进入左侧“账号管理”。管理员可管理所有试点账号；管理员标识与分析负责人、决策负责人、补证成员这三种业务角色分开。

## 新增成员

点击“新建账号”，填写登录账号和显示名称，选择成员需要进入的工作区，并分别指定业务角色，点击“创建账号”。系统生成随机口令，当次显示后请复制交付给成员；关闭后无法从列表中查回，遗失时使用重置口令。

登录账号由 3–100 位字母、数字、点、下划线或短横线组成，以字母或数字开头，统一小写。每个账号至少分配一个工作区；成员只能进入分配的工作区。新增成员不会自动成为某个项目的分析负责人或决策负责人，项目负责人仍按项目配置。

## 配置和停用

点击账号，修改显示名称、工作区角色或账号状态后保存。登录账号和管理员标识在界面中不能修改。停用、工作区或角色变更会撤销该成员的旧会话；已有业务记录保留。重新启用后成员可重新登录。

当账号已被其他操作更新，界面会提示版本冲突；重新选择账号读取最新状态，再确认自己的修改。管理员不能在这里停用自己或改变自己的工作区权限。

## 重置口令

选择目标账号，点击“重置口令”并确认。旧口令和旧会话失效，新随机口令只显示当次。管理页不读取原口令，也不向账号列表或审计写入口令。管理员修改本人口令使用右上角“修改密码”入口，不使用为其他成员生成随机口令的重置操作。

创建或重置时若网络中断，不要假定操作失败；先刷新列表核对账号，再按最新版本执行重置。客户端不自动重复提交。

## 修改管理员本人的密码

登录管理员账号后，点击右上角“修改密码”，填写当前密码、新密码并再次确认。新密码须为 12–1024 个字符，不能与当前密码相同；密码按输入原样处理，不自动去除首尾空格。

保存成功后，该管理员在所有浏览器和工作区中的旧会话都会失效，页面返回登录页。请使用新密码重新登录。其他成员的口令和会话不受影响；系统不回显或记录新密码，也不改变管理员的业务权限。

当前密码不正确时不修改口令。同一账号在登录限速时间窗口内达到失败上限后，修改密码暂时受限（默认 15 分钟内 5 次），稍后再试。若提交时网络中断，结果可能已生效，请尝试使用新密码重新登录；系统不会自动重复提交改密请求。

## 服务器初始化和恢复

在已初始化至少一个工作区的 pilot 环境中执行：

```sh
python -m app.pilot.cli create-admin --username admin --display-name Administrator
```

该命令创建具有全局账号管理权限的账号，并以补证成员加入所有现有工作区。随机密码在该次命令输出；运行时应将输出重定向到权限 0600 的私有文件，不写入源码或部署日志。命令遇到同名账号会拒绝，不重置或提升已有用户。

控制库从 v1 升级到 v2，增加管理员标识、账号版本及管理审计。上线前须停止本项目 API、worker 和 gateway，并备份控制库及所有工作区库。旧镜像不支持 v2；回滚必须恢复升级前备份或采用兼容版本，不能仅切回旧镜像。详细备份流程见 [部署恢复指南](deployment.md)。

本轮 admin 初始密码通过本地忽略目录 `api-key/` 内的私有交付文件提供。团队入口为 https://product.ezarouter.cc，不复用或公开服务器凭据。

改密功能于 2026-09-24 完成上线验证，详见 [发布回执](self-password-receipt-2026-09-24.json)。本次上线未修改任何现有账号的密码。
