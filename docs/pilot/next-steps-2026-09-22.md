## 第二批：独立试用所需的资料与访问能力

1. **D2 收尾**：先确定共享资料留存位置，再补数量阶梯报价、样品/现货/定制 MOQ 区分、左右前排检查项。原件应让团队可访问，不仅是一段本机文件名；首轮可用有权限的稳定共享链接，不必立即做完整附件平台。
2. **D6 来源刷新与额度**：展示当前剩余请求数、采集时间/范围、缓存或新查询的区别，明确刷新动作和未知结果恢复；验证同商品新观测、去重及失败恢复。9/21 最后核验的市场来源配额曾为 1/1；本地模板不等于 ECS 现场值，开展下一轮前须读取现场配置再确定有限额度。
3. **入口可持续使用**：目前 SSH 隧道会受本机进程退出影响。先提供可重复使用的启动、健康检查和故障恢复说明，实际验证合作团队自己的访问；每个成员使用自己的业务账号，不共享 root。用户提供 Cloudflare 子域名后，再接 HTTPS 并复验 Cookie/Origin/CSRF。
4. **职责落到真实人员**：明确分析负责人、采购协作和决策负责人；为内部团队候选建立具体任务和期限。观察合作团队仅用页面完成已有材料的录入与评估，不依赖 Codex 或脚本代操作。

## 第三批：完成真实验收

- 材料就绪后由分析负责人核对 AI 草稿并保存正式评估，决策负责人作真实决定。根据阶段合理性确认新标准版本；准备阶段切换不自动放宽正式初筛。
- 对继续打样的产品，按明确车辆配置、左右前排和样品版本完成实测记录；缺车辆/样品保持阻塞，桌面说明不代替实车验证。
- 有真实批准与结果材料后，执行真实复盘节点，验收 9.2。结果用真实表格或人工填写，费用缺失不补零。
- 合作团队与内部团队各走通适用的完整闭环，反馈由负责人确认并在下一项目采用；按经确认的范围验收 9.3。未上市或研究停止都必须有真实原因，不能拿研究闭环冒充上市效果。
- 记录各节点用量、失败比例、补证次数、返工和人工工时；不以单次 6729 tokens 外推平均用量，不预设工时改善门槛。

## 国内货源自动化与后置能力

- 1688/义乌购当前只有链接平台与商品编号识别，尚无真实详情连接器。后续先取得应用权限及可用样本，核对实际价格/MOQ/规格字段，再只选一个源接入。
- 自动提取只能产生待核验资料；公开起售价和 MOQ 不能直接成为正式采购条件。线下厂商录入继续保留，可先完成试点，不以国内接口授权作为先决条件。
- 更多渠道、ERP/店铺自动同步、自动采购/上架/投放、多 Agent 自主编排和模型训练继续后置。
