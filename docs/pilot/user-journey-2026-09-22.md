# 业务入口与使用链条调整

本次围绕“创建项目 → 收集候选 → 补充资料 → 评估与决策 → 获批验证 → 结果复盘”重排现有能力。保持既有审批、证据版本、团队隔离与真实数据口径。

## 使用变化

- 工作台：先处理自己的事项，等待他人折叠展示，随后是进行中的项目；首次进入可直接新建项目。
- 新建项目：业务方向、负责人两步；保存草稿后进入标准确认；采用已确认反馈的项目直接继续收集候选。
- 项目：候选清单与添加候选优先，标准、设置、事项、历史在次级视图；必需材料使用中文清单。
- 候选：顶部显示当前工作、负责人和下一步；四个业务阶段依次展开；继续观察和停止研究保留为决策分支。
- 补证：事项直接打开对应报价、价格、适配或核验表单；分配负责人为独立动作。录材料不会自动核验或自动完成任务。
- 全部事项：按项目、负责人、状态和逾期筛选；已有任务保留进度与结论操作。试用观察移到次级入口。

## 事项一致性

新增只读 GET /api/v1/work-items，由已有业务记录计算。工作台、项目和候选共用稳定事项标识；当前阶段才要求的材料进入队列；已有证据任务替代相同字段的派生缺项，逾期是事项属性。OEM 研究参考材料可满足研究准备，但不能替代正式采购证据。
