# AI 草稿时效与调用用量（D4＋D5）

2026-09-22 已部署到独立 ECS 试点。变更已归档：[improve-ai-draft-freshness-and-usage](../../openspec/changes/archive/2026-09-22-improve-ai-draft-freshness-and-usage/tasks.md)。

## 使用方式

- 候选「评估整理」优先展示最新成功且未过期的草稿。旧稿保留历史；证据替代、到期、标准或退回问题变化时显示过期原因。
- 已复制的草稿失效后，保存暂停，但人工输入保留。可重新整理并复制新稿，或明确选择「保留输入并转为纯人工草稿」后重新核对保存；重新发起整理不会静默清除原来的来源关联。
- 候选页「模型调用记录」默认折叠。展开查看每次调用的节点、模型、已知输入/输出/总 token、耗时、请求上限、结束原因、状态与费用，支持当前候选 CSV 导出。
- 已知用量、部分已知、未知和历史未记录尝试分别计数。未知不等于零；费用只有服务返回时才记录，按币种分别汇总，不从 token 擅自推价。
- 后台成功任务及候选时效定期刷新，最终保存仍以服务端当前依据为准。复盘仍绑定所选结果版本及原批准评估，不把后来补证冒充原批准依据。
