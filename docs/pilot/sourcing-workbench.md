# 补证与采购材料工作台

打开候选的“补证”阶段，先看本阶段需要哪些材料及各字段的负责人、期限。字段旁的操作打开对应专用表单；原始证据、AI 清单与初筛详细记录保留在折叠区域。

## 三类常用录入

| 需要补充什么 | 使用哪个表单 | 核心口径 |
| --- | --- | --- |
| 采购报价和 MOQ | 供应商报价 | 供应商名称、参考价/供应商确认价、币种、每件/每套、每套件数、起订量及单位 |
| 当前售价或目标售价 | 售价与套装 | 实际在售报价和目标估算分开，保留来源、时间及套装数量 |
| 车辆适配 | 车型适配 | 品牌、车型、年款、配置、座椅类型，资料检查/实车测试，检查记录及样品编号 |

线下厂商可直接选择“线下对接”，填写厂商名称以及报价单文件名、日期、页码等可追溯来源。联系信息、交期、贸易条款、税费和运费可补充记录。供应商确认过的价格不代表录入人已经核验；只有写明核验依据才可标记已核验。

首次保存是独立材料；修订旧材料时必须明确选择替代记录。两家供应商不同报价不能悄悄互相覆盖。材料保存不会自动完成补证任务；负责人应在任务页关联证据并更新结果。OEM 研究阶段的参考价、参考 MOQ 和目标价任务可完成资料收集，原始材料仍保留未核验或估算状态。正式初筛仍需根据确认标准重新执行。

## OEM 的阶段要求

- **研究准备**：先记录货源参考价、页面 MOQ、目标售价和适配资料检查，保留未核验或估算标签。
- **打样准备**：补供应商正式报价、MOQ 与明确车辆配置。实车适配是后续需要验证的结果，不假装已经完成。
- **上市准备**：补实车样品适配与实际售价。

变更目标车型或座椅配置后，旧实车适配结果会失效，必须重新核验。

阶段只表达材料准备计划，不代表已批准打样、采购或上架。项目已确认的初筛标准和历史决策不会因为选择 OEM 而更改；需要调整正式标准时仍由项目负责人确认新版本。

## 国内货源当前可以自动做什么

本轮可从支持的 1688、义乌购和 Alibaba 商品链接识别平台与商品编号，不下载页面内容。价格、MOQ、供应商和商品属性仍需依据页面、报价单或对方回复录入。

1688 官方商品接口与义乌购商品/商铺合作接口具有接入可能；目前没有本项目的应用授权或接口凭据，因此页面显示需要授权。正式接入需先确认账号资质、商品权限、实际字段与调用额度，再实现适配器并做真实查询验收。
