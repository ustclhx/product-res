# 管理员账号交付验收 · 2026-09-21

用户要求新增 `admin`、生成随机密码，并能在页面新增和配置成员。已部署独立账号管理页 `/admin/accounts`，支持创建、显示名称、启停、工作区及业务角色、随机重置口令。管理员权限由服务端指定，普通成员不可提升自己。

## 验证证据

- `make check` 通过：141 项后端测试，Ruff、mypy、前端 lint/build、2 项前端请求键单元测试。
- Pilot 浏览器 4 项通过，其中管理员场景实际覆盖新增账号后登录、显示名称和角色修改、停用/启用、重置后旧密码拒绝及新密码登录，普通成员导航隐藏且管理 API 返回 403。
- 桌面和 390px 窄屏页面已目视检查；截图使用离线测试账号并收起口令。
- 控制库 fresh/v1/v2 并发构造通过；v1 密码哈希保持不变，升级在同一写事务中重新检查版本。管理员操作在写事务中再次检查有效管理员会话。
- 重复引导创建 `admin` 会拒绝，原账号和原密码保持有效；未通过覆盖旧用户取得管理员权限。
- OpenSpec `add-pilot-account-admin` strict 校验通过。

外部 OMP 审查被自动审批拒绝，理由为可能外传未公开源码；未绕过限制，改由主代理本地审阅并运行上述检查。不存在外部独立审查通过的声明。

密码未写入本文、测试数据、镜像或源码；交付文件为本机忽略目录 `api-key/admin-login.txt`，权限 0600。服务器私有 operator 目录另保留初始化回执。管理页操作说明见 [账号管理](account-administration.md)。
