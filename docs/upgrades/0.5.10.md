## 概要

修复 0.5.4 起记录的两个已知问题：英文营销页约 0.118 的整页位移（CLS），以及 share-cards e2e 连续运行时的偶发失败。

- **语言建议横幅不再在水合后把整页下推**（主因，0.118 = 横幅高 97px / 视口 823px）：
  - 原实现在水合后按 Accept-Language 询问服务端，再在页面顶部插入「是否切换到中文」横幅；浏览器语言非默认语言的访客
    （Lighthouse 继承本机中文环境时也是）在 `/`、`/pricing` 上看到整页下移，`/zh` 不建议所以为 0。
  - 现在由 `<head>` 内联脚本（`apps/web/src/features/i18n/suggestion.ts`）在首帧前按 `navigator.languages` 与偏好 Cookie
    决定，给 `<html>` 写 `data-locale-suggestion`；服务端 / 预渲染输出每个候选语言的隐藏横幅，只显示匹配的一条，首帧即在最终位置。
  - 横幅首帧可见而营销页首帧后才水合，按钮做了渐进增强：「切换语言」是指向目标语言地址的真实链接（无 JS 也能切换），
    水合前的点击由同一脚本的委托监听写入与 `rememberLocale` 相同的 Cookie；水合后交给 React，同一次点击不会处理两次。
    水合前点击切换时，已登录账号的语言不会同步保存（目标页按 URL 显示语言，不受影响）。
  - 删除不再使用的服务端函数 `getLanguageSuggestion`、`preferredLocale` 与文案 `i18n_suggestion_failed`；营销页少一次 server function 请求。
    地区语言标签（如 `pt-BR`）改为不区分大小写匹配。
- **Inter 的度量匹配回退字体**（次因，只在慢网可见）：字体栈改为 `"Inter Variable", "Inter Fallback", …`。
  `Inter Fallback`（`packages/ui/src/styles/globals.css`）用本地 Arial / Liberation Sans / Arimo 按 Inter 的宽度与纵向度量缩放，
  `unicode-range` 与 Inter 拉丁子集一致；Inter 晚于首帧到达时换字不再改变换行（手机端定价页 / 博客页约 0.02 / 0.013 → 0）。
  Inter 加载后外观不变；Inter 完全加载失败时，拉丁字符改由缩放后的 Arial 显示（此前为系统字体）。没有这些本地字体的平台（如 Android）行为不变。
- **share-cards e2e**：分享卡片、卡片图片与预览接口共用 `shareCard` 限流（同一 IP 60 秒 30 次）。e2e 中不带模拟 IP 的请求共用一个桶，
  多个 spec 连续运行时出现 429。现在 `share-cards.spec.ts` 用 `page.request`（带页面的模拟 IP），访问 `/dev/ui` 的
  `ui-preview.spec.ts`、`floating-controls.spec.ts` 每个用例使用随机 IP。产品限流不变。

测量（`lighthouse@13.5.0` 移动端 simulate，两版交替运行取中位数）：

| 页面 | CLS 前 → 后 | LCP 前 → 后（ms） |
| --- | --- | --- |
| `/` | 0.1179 → 0 | 1961 → 1961 |
| `/pricing` | 0.1179 → 0 | 5438 → 5490 |
| `/zh` | 0 → 0 | 1812 → 1962 |

simulate 下 `/zh` 的 LCP 在两版中都在约 1810 / 1960 ms 两个值之间跳动（取决于延迟样式表请求在模拟中的起始时刻）；
devtools 实测节流下三页 LCP 不慢于修改前（`/zh` 1193 → 1136 ms）。加载完成后的整页截图与修改前逐字节一致（16 组）。

## 配置变更

无。说明：

- 项目在 `brand.css` 用 `--font-sans` 换掉 Inter 时，新字体栈不含 `"Inter Fallback"`，回退字体规则不生效；
  若自己的字体同样以 `font-display: swap` 加载，可参照 `globals.css` 为它定义度量匹配的回退字体（`docs/design-system.md` 已写明）。
- 项目代码若调用了已删除的 `getLanguageSuggestion` / `preferredLocale`，改为读取 `<html data-locale-suggestion>`
  或复用 `features/i18n/suggestion.ts`。
- 项目自定义了语言建议横幅时，请让横幅在服务端输出、首帧前决定显示，否则仍会出现同样的整页位移。
