## 概要

衍生项目第一次在项目内跑通全量离线 e2e 与 Nightly 后反馈的模板侧问题（OpenSpec `harden-derived-project-checks`）：用例与 Nightly
按项目配置运行，Badge 灰色底与品牌强调色分离，Select 不再撑开所在列。

- **e2e 用例按项目配置运行**（`apps/web/e2e`），不适用时 `test.skip` 并写明原因：
  - `share-cards`：卡片地址 `v=` 接受项目字体 / 站点覆盖带来的第二段指纹（`1-xxxxxxxx-xxxxxxxx`），过期地址只替换 `v`；
  - `signup-bonus`：`billing.signupBonusCredits` 为 0 时跳过；
  - `analytics` 答案页用例：`features.guides` 关闭时跳过；
  - `admin-model-params`、`ai-media`：Workers AI 用例只在 `ai.mediaProviders` 含 `workers-ai` 且 `apps/web/wrangler.jsonc` 有 `ai` 绑定时运行（新增 `e2e/workers-ai.ts`）；
  - `floating-controls`：首页没有声明 `body[data-floating-controls]` 时跳过；
  - 价格目录：新增 globalSetup `e2e/catalog-setup.ts`，用例前写入示例目录（幂等，只写 `product_res_wt_*` 隔离库），结果不再依赖用例顺序；
  - `admin-billing`：夹具套餐与价格在用例结束时停用。
- **Badge 中性底**：新增设计 token `--neutral-fill`（浅 `#e5e5e5` / 深 `#525252`，与 `--accent` 默认同值），灰色实心 Badge 改用它；
  品牌层改写 `--accent` 不再影响灰色徽标。默认主题外观不变；预设对比度测试新增此组合。
- **SelectTrigger**：外层包装 `min-w-0`、触发器 `max-w-full`，放进 grid / flex 列时长选项截断而不撑开所在列。
- **Nightly**：`e2e-multi-tenant` 在衍生项目（有 `.template-base.json`）且 `template.config.ts` 未开启 `multiTenant` 时跳过并写入任务摘要；模板仓库照常运行。
- `scripts/production/check-wrangler-envs.d.mts`：为 `parseJsonc` 补类型声明。
