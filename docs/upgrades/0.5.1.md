## 概要

- **手机端语言与主题控件移入页脚**（staging 验收 UI-01）：小于 768px 时，根布局不再悬浮语言选择与主题切换（它们遮挡正文），
  改为随页面滚动的一行设置（新组件 `apps/web/src/features/theme/site-settings.tsx` 的 `SiteSettings`）：
  - 有站点页脚的页面：`SiteFooter` 在版权行上方渲染这一行，页脚带 `data-site-footer` 属性；
  - 没有站点页脚的公开页：根布局在页面末尾渲染同一行；页面上存在 `[data-site-footer]` 时用 CSS 隐藏，不会重复；
  - 只有「Ask AI」继续悬浮，手机端贴底（`bottom-4`），md 及以上仍在浮动主题切换上方（`bottom-18`）；
  - 手机端设置行与页脚底部始终留 80px，右下的其他悬浮按钮（如 SubjectChat 触发器）不遮挡设置行与版权（UI-03）；
  - 768px 及以上桌面不变；工作台、后台、认证页本来就有内联控件，不受影响。
  设计稿副本：`docs/design-system/prototypes/mobile-footer-controls/`。
- `LanguageControls` 新增 `suggest` 属性（默认 `true`）；页脚设置行的实例传 `false`，同页只由根布局的浮动实例请求语言建议。
- **营销 Stats 区块**（UI-02）：窄屏格内数值改用 `text-title` 并允许任意处断行，长数值换行而不是被裁切；md 及以上不变。
- **对话页加载骨架拆成独立模块**：`ChatPageSkeleton` 从 `features/ai/chat-page.tsx` 移到 `features/ai/chat-page-skeleton.tsx`，
  避免路由的 `pendingComponent` 把整套对话 UI 拉进客户端入口包。
- **设计规范以仓库为唯一来源**：`docs/design-system.md` 与 `ui-design` 技能明确 claude.ai 的 Design System / Design 画布 Artifact 只是按账号私有的缓存，
  打不开时在当前账号按仓库重建，不请求分享，链接不写回仓库；原型索引的画布链接只是确认记录，实现与验收以副本文件为准。
- OpenSpec `add-ui-design-system` 已全部验收并归档，规格并入 `openspec/specs/`（design-system、app-workbench、marketing-site、agent-skills、project-bootstrap）。

## 已知问题

- **自定义页脚的项目**：项目自己实现页脚（不用 `SiteFooter`）时，手机端设置行会出现在根布局的页面末尾、页脚之后。
  希望放进自己的页脚时，在页脚根元素加 `data-site-footer`，并在其中渲染 `<SiteSettings className="border-t py-4 md:hidden" />`，页脚底部留 `pb-20`。
- **组件测试**：渲染 `SiteFooter`（或 `MarketingShell`）而未搭建路由的测试会因 `LanguageControls` 读取路由位置报错，
  按模板 `share-page.test.tsx` 的做法 mock `features/i18n/language-controls.tsx`。
- 桌面端 SubjectChat 的 panel 变体触发器与浮动主题切换同在右下，可能重叠（#373），后续版本处理。
