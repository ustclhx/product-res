## 概要

衍生项目采纳 0.5.7 / 0.5.8 后，在项目配置下回报的跟进：e2e 跳过条件与原因、测试夹具对同库 e2e 的影响、一个时序不稳的单测，
以及 Select 在窄列中的用法说明。

- **`floating-controls` e2e**：不再要求语言与主题两个浮动控件同时存在，只核对首页实际存在的控件；两个都没有时跳过（「首页没有浮动的语言或主题控件」）。
  适用于只保留其中一个浮动控件的站点（如语言菜单移入页头、主题切换仍浮动）。
- **跳过原因**：`redirect.spec.ts`（`auth.oauth 未包含 google`、`auth.magicLink 已关闭`）与 `i18n-routing.spec.ts` 中未写原因的 `test.skip` 补上原因文本。
- **`apps/jobs/test/server-analytics.test.ts`**：夹具套餐与价格以停用状态写入。此前同一隔离库先跑 `pnpm test` 再跑 e2e 时，
  这些 `credit_pack` 会进入公开定价目录，让定价数量断言失败。
- **`packages/ui` dropdown `openOnHover` 测试**：改为等待状态而不是固定 30ms，完整并行 `pnpm test` 负载下不再偶发失败。
- **Select 窄列用法**：0.5.7 给触发器加的 `max-w-full` 只在列不窄于最小宽度（160px / compact 128px）时生效——CSS 中 `min-width` 优先于 `max-width`。
  模板没有改默认最小宽度：实测 `min(160px,100%)` 会在工具栏（`inline-flex`、grid `auto` 列）中把触发器缩到文字宽度（160px → 52px）。
  比最小宽度更窄的列请在 `SelectTrigger` 上传 `className="min-w-0"`（tailwind-merge 覆盖默认最小宽度），`docs/design-system.md` 已写明，并新增测试。
