## 概要

- **提示词评测两个可选扩展点**（OpenSpec `add-eval-extension-points`，`packages/evals`）。未声明时行为、报告判定与退出码不变；
  完整契约见 `docs/06-ai.md`「被评正文转换与评测后门槛」。
  - **`prepareOutput`**：套件可声明带版本号的正文转换 `{ version, run({ rawOutput, sample, prompt }) → { output, annotations? } }`，
    在确定性检查与评委之前执行，检查与评委都评转换后的正文；三种模式同一路径。hook 抛错、返回不合法或两次结果不一致时样本记
    新状态 `prepare-error`（退出码 1），不回退为原文。生成录制仍保存原文；评委录制的 `outputHash` 改为被评正文摘要并记录
    `prepareVersion`，转换版本或正文变化时旧评委录制判 `stale-recording`。报告样本带 `prepared`，报告目录写 `outputs/<id>.txt`
    （改变时另写 `.raw.txt`）。
  - **`evaluateRun`**：候选与基线全部完成后调用一次，接收选定范围内每个样本的完整结果（状态、检查、评委各维原始分与错误、
    生成 token 与 `durationMs`、模型与评分标准版本）和运行范围，返回 `{ gates: [{ id, status: passed|failed|incomplete, detail, required?, metrics? }] }`。
    结果写入 `report.json` 的 `assessment` 与 `report.md` 的「Gates」；`failed` 或必需 `incomplete` 以**新退出码 5** 退出，
    排在 1、3、4 之后，不掩盖已有失败；内置总分回退判定照常生效。
  - **统计辅助**（从 `@<scope>/evals` 导出）：`collect(group, ids, pick)`（按样本 ID 收集并列出缺口）、`percentile`（最近秩）、`mean`，
    以及类型 `EvaluateRun`、`EvaluateRunContext`、`EvaluationGroup`、`EvaluationResult`、`RunGate`、`RunAssessment`、`RunScope`、
    `PrepareOutput`、`PreparedOutput`、`PreparedInfo`、`SampleStatus` 等。
- **生成耗时**：真实 / 录制模式把生成耗时写入生成录制的可选字段 `durationMs`；回放读取录制值，旧录制为空。
- **报告新增字段**：`scope`（总样本数、选定数、是否经 `--samples` / `--tag` 筛选）、`prepareVersion`、`assessment`、
  `baseline.scoredPairs` 与 `baseline.baselineFailures`（同次回放基线失败的样本，此前会被平均分对比静默排除）、
  `summary.expectedScores`，样本 `usage.generation.durationMs` / `usage.judge.durationMs`。筛选运行时 `report.md` 标明范围。
- 评委 JSON 解析失败仍记 `judge-error` 并判样本失败，不自动重试。

## 验证

```sh
pnpm --filter @<scope>/evals test
pnpm --filter @<scope>/evals typecheck
pnpm eval:prompts --suite example --baseline product-intro@v1   # 以 0 退出，report.json 的 assessment 为 null
```

采纳扩展点的项目套件（例如从旧评测脚本迁移）：

1. **转换后再检查与评委** → `prepareOutput`。把旧脚本里「先保存原文、再调用线上兜底函数、用结果跑检查与评委」的那一步，
   改为在 `evals/<suite>/suite.ts` 声明：

   ```ts
   prepareOutput: {
     version: 'guard.v4',
     run: ({ rawOutput, sample, prompt }) => {
       const { text, stats } = deliveredText(rawOutput, sample.input, prompt.promptVersion)
       return { output: text, annotations: { glyphs: stats.glyphs, unresolved: stats.unresolved } }
     },
   },
   ```

   请求年份等复算输入放进样本 `input`，不要读当前时间。旧评委录制若是对原文打分的，回放会判 `stale-recording`，
   需要用 `--record` 重录评委（生成录制可保留）。`--baseline` 用到的基线版本也经过同一转换，其评委录制同样要重录；
   报告 `baseline.scoredPairs` 小于 `comparedSamples` 或 `baseline.baselineFailures` 非空时，说明内置平均分对比只覆盖了部分样本。
2. **逐维差值、绝对分、P95 门槛** → `evaluateRun` + `collect` / `mean` / `percentile`。旧脚本中「过滤掉缺失评分再求均值」的写法
   改为 `collect` 并在 `missing` 非空时返回 `incomplete`；示例见 `docs/06-ai.md`。
3. **生成耗时**：P95 时长门槛需要录制带 `durationMs`。旧录制没有该字段时 `collect` 会列为缺口；可重新录制，或在确有
   真实耗时来源时把它补写进录制的 `durationMs`（来源需可追溯，不要用回放耗时）。

## 回滚

回退代码即可，无数据与配置变化。回滚到 0.5.2 后，带 `durationMs` / `prepareVersion` 的录制会被旧版本判为不合法，
需删除这两个字段或重新录制。
