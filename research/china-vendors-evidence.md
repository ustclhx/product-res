# 中国本土面向跨境卖家的 AI 选品 Agent：一手证据

核验日期：2026-09-16（按页面当前可访问状态记录）。范围是中国本土厂商、面向跨境卖家、公开材料明确出现“Agent/智能体/MCP+选品”或可复核的 AI 选品流程。结论分为：**官方宣称**（页面原文/直接功能）、**可验证流程**（帮助文档给出操作步骤）、**推断**（由功能组合推导）、**未找到证据**（不能据公开材料断言）。

## 1. 卖家精灵 SellerSprite：Agent/MCP 连接 Amazon 数据，选品分析仍以洞察为主

- **产品/可用性/日期**：开放平台公开提供 API、CLI、MCP、Agent 四种接入；Agent 是“自然语言提问、AI 自动分析数据、生成可视化图表、导出分析报告、多轮对话上下文”。页面截至核验日可访问，未见明确上线日。官方开放平台：[open.sellersprite.com](https://open.sellersprite.com/)。
- **用户**：Amazon 卖家/运营团队、要把 Amazon 数据接进自研 AI 应用的开发者。页面称覆盖 10 个 Amazon 站点、2 亿+ ASIN、500万+关键词（官方宣称）。
- **需求→数据→候选→验证→上架/投放**：可验证的是：用户自然语言提问或通过 MCP/Agent 发起分析；“选品分析”按销量、价格、评分等维度筛潜力商品；随后可做关键词研究、竞品监控、市场分析、评论分析、定价和广告优化。平台页给出“选品分析”“基于销量、价格、评分等多维度数据，快速筛选潜力商品”，以及竞品价格/销量/评论变化、评论痛点、PPC 优化等能力。公开材料没有显示 Agent 自动创建采购单、Listing 或广告的完整闭环；这些仍需卖家在其 ERP/平台执行。
- **数据源**：SellerSprite 自有 Amazon 商品/ASIN、关键词、销量/价格/评分、市场和评论数据；开放平台写明 40+ 数据接口，API/CLI/MCP 可调用。属于**外部市场更新**。
- **行动权限**：Agent 页面证据只支持查询、分析、图表、报告导出；未找到公开证据证明它可直接上架、采购或投放广告。MCP 是“AI 自动选择工具调用”，工具调用不等于外部写权限。
- **私有店铺数据回流**：未找到公开证据证明开放平台 Agent 能读取卖家自有店铺订单、库存、利润或广告实绩；页面重点是 Amazon 市场公共数据。因此不能据此判定私有数据闭环。
- **反馈是否改变下一轮选品**：有多轮对话上下文和竞品监控，但未找到“投放/销售结果自动回写、训练或改变下一轮候选排序”的一手证据。结论：外部市场更新强；经营闭环、学习闭环未证实。
- **关键短摘**：官方页写“API · CLI · MCP · Agent — 连接 AI 与 Amazon 数据洞察”“选品分析：基于销量、价格、评分等多维度数据，快速筛选潜力商品”“AI 自动分析数据”“导出分析报告”（[同一官方页](https://open.sellersprite.com/)）。

## 2. Sorftime：跨平台数据 MCP，公开宣称有“AI选品”工具与组合式调研

- **产品/可用性/日期**：Sorftime MCP 页面当前可访问性受超时影响，但搜索抓取到的官方页面内容明确写有 MCP 和 AI 选品。Sorftime 官方“关于我们”页称 2025 年 12 月行业首发跨境电商专用 MCP。页面：[sorftime.com/en-US/mcp](https://www.sorftime.com/en-US/mcp)；时间说明：[关于我们](https://sorftime.com/en-US/home/aboutus)。
- **用户**：跨境电商卖家、企业研发和使用 Claude/Gemini/GPT/豆包/通义等大模型的运营团队。官方示例以“调研市场”命令为入口。
- **需求→数据→候选→验证→上架/投放**：官方描述 MCP 已上线工具包括：单产品/趋势/子体/评论分析/AI选品；类目市场竞争/趋势/头部产品调研/AI选品；关键词热搜趋势、搜索排名竞争、搜索位竞品分析/AI选品。官方示例称大模型可自主组合“热销 Top100 产品 + 市场趋势 + 产品详情 + 买家评论”形成分析结论。故可验证流程是：自然语言需求→MCP 自动选择多个市场工具→输出候选/市场结论→卖家人工验证。未找到公开证据证明 MCP 会自动采购、创建 Listing 或投放。
- **数据源**：官方称已支持 Amazon、TikTok Shop、Walmart、Shopee、Temu 及 1688 供应链（站点数量随页面和版本变化，不将单页数量外推为统一覆盖）；另有产品、市场、关键词的结构化 API/CLI。既有**外部市场更新**，又可能通过 1688 供应链支持货源验证。
- **行动权限**：MCP 页面证据是查询、组合工具、生成结论；API/CLI 提供结构化原始数据。未找到写入平台/采购/广告的公开权限说明。
- **私有店铺数据回流**：未找到“绑定自有店铺订单/库存/利润并回流 AI 选品”的公开证据；目前公开叙述仍是平台市场数据和 1688 供应链数据。
- **反馈是否改变下一轮选品**：官方称有产品趋势、listing 动态、监控功能，但未找到销售/投放结果自动反馈给下一轮 AI 选品的证据。结论：外部市场更新强，经营闭环和学习闭环未证实。
- **关键短摘**：官方页面写“已上线工具可为大模型提供功能……产品：……AI选品；类目市场：……AI选品；关键词：……AI选品”，并举例模型自主组合 Top100、趋势、详情、评论（[MCP 官方页](https://www.sorftime.com/en-US/mcp)）。

## 3. LinkfoxAI：选品、刊登与经营数据三段已具备，自动反馈选品仍待核验

主代理补充核验了选品页链接的智选测款、店铺经营和授权文档，以下结论取代只看选品首页时的保守判断。

- **选品入口**：输入站点、品类/关键词、ASIN、价格与利润要求，生成候选并保存来源、任务及处理状态。[选品分析](https://wiki.linkfox.com/features/product-selection)。
- **执行工作流**：智选测款依次完成商品池、条件过滤、市场评估、需求验证、利润测算、风险检查、决策报告、Listing 生成、SP-API 刊登。前六步可自动跑，报告阶段需人工确认。最后一步是真实提交；部分 Listing 仍需补价格和库存才能启售。权重由用户配置；成本中的广告和退货损耗包含预估值。**因此不能说它只出报告，也不能把刊登完成说成完成真实销售测试。**[九步工作台](https://wiki.linkfox.com/solutions/smart-product-test)。
- **外部数据**：上述九步文档列出 Amazon、卖家精灵、SIF、Google Trends、ABA、极目、Keepa、1688，以及风险检查数据服务；这是厂商披露，未实测接口覆盖。
- **自有数据**：经营助手文档明确，经 Amazon 官方 API 完成店铺和广告授权后，自动同步销售、广告、库存、结算、售后和绩效，可下钻单个 ASIN。[店铺经营助手](https://wiki.linkfox.com/features/store-operations)。
- **授权边界**：另有 Skill 授权路径，覆盖数据读取、商品管理与广告；具体能力依权限和模块。[店铺授权](https://wiki.linkfox.com/resources/shop-authorization)。
- **闭环判断**：研究→刊登已有可核验流程，自有经营数据回流也有独立模块；未找到把测试结果自动关联到原始推荐，并据此更新下一轮选品权重/排序的文档。可认定具备人工经营闭环的主要环节，自动决策反馈尚未证实。

## 4. 积加 AI：ERP 私有数据 + 数字员工/MCP，具备搭建选品 SOP 的底座，但选品技能需逐项核验

- **产品/可用性/日期**：积加官方帮助中心“积加AI产品介绍”最近修改日期为 2026-08-18；登录入口为 [aiagent.app.gerpgo.com](https://aiagent.app.gerpgo.com)。
- **用户**：使用积加 ERP 的跨境企业、运营团队、需要数字员工长期任务的组织，以及希望把 ERP 数据接入自研智能体的研发团队。
- **需求→数据→候选→验证→上架/投放**：官方明确提供智能对话、技能中心、长期任务、数字员工、MCP 市场和技能创作中心。可验证流程是：注册→授权关联 ERP（可选）→选择/创建技能→以自然语言提问；长期任务可让数字员工按周期输出“异常商品分析报告”等 SOP 产出；MCP 市场可将积加 ERP/第三方数据封装给外部 AI。官方场景示例是新品/旗舰品数据分析，或让数字员工做商品月度监控、广告日常监控。**未找到官方现成“AI 选品”技能的公开操作页**，因此不能把它写成已交付选品 Agent；可确认的是它允许企业自定义选品技能和 SOP。
- **数据源**：授权后可使用积加 ERP 的商品/产品/店铺数据；官方要求绑定 ERP 管理员手机号并提示权限/数据权限不足会导致分析不完整。另有 MCP 市场第三方数据。这里是五家中最明确的**私有经营数据入口**。
- **行动权限**：权限分为 ERP 权限、功能访问、功能操作，子账号可被限制到部分商品/产品/店铺数据；但 AI 是否能执行上架、采购、广告写入取决于具体技能和 ERP 权限，公开总览未证明默认可写。
- **私有店铺数据回流**：明确支持 ERP 授权和按账号/店铺/商品数据权限隔离；这证明“数据可回流 AI 分析”，但没有证明这些结果自动改变下一轮选品候选。
- **反馈是否改变下一轮选品**：长期任务和商品/广告监控可形成**经营闭环候选**（定期复盘、人工检验）；没有公开证据证明选品规则、权重或排序会依据结果自动调整，学习闭环未证实。
- **关键短摘**：官方写“长期任务……比如：需要数字员工A每天输出一份异常商品分析报告”；“MCP市场：将积加ERP数据、各三方数据封装为MCP接口”；“授权配置……是否需要积加ERP数据来做AI分析”；数字员工可按明确 SOP 周期运行（[帮助中心](https://help.jijiaerp.com/docs/rk4iD1LM)）。

## 5. 赛狐 AI：ERP 内嵌 AI 经营分析/VOC/广告，选品洞察明确，自动选品写入未证实

- **产品/可用性/日期**：赛狐官方 AI 产品页当前可访问，未见明确上线日期。[官方页面](https://www.sellfox.com/function/ai)。
- **用户**：跨境电商卖家，尤其使用赛狐 ERP 管理商品、广告、库存和售后的运营团队。
- **需求→数据→候选→验证→上架/投放**：官方产品矩阵包含 AI 文案生成/优化、AI 生套图/视频、AI 广告助手、AMC 投放策略推荐、Review/VOC 分析、AI 数据洞察、仪表盘 AI、AI 财务复盘。与选品最直接的是 Review 分析：官方称“选品时，高效收集竞品槽点，找准切入关键点”；AI 数据洞察可从经营总览→商品诊断→销量归因识别问题和增长机会。流程可验证为：读取竞品/自身评价及 ERP 商品经营数据→提炼痛点/机会→人工决定候选与 Listing/广告；页面未给出“输入需求自动生成候选商品池”的选品 Agent 页面。
- **数据源**：全网评价、商品/Listing、关键词/ABA 报告、搜索词/广告、小时级出单、店铺经营数据、利润数据。既有**外部市场/评论更新**，也有**私有经营闭环**。
- **行动权限**：AI 文案结果可用于 Listing；广告助手给关键词、低效词、潜力词和预算建议；AMC 可“一键采纳创建”广告方案（官方宣称）。但未找到 AI 自动采购或自动上架新商品的公开证据。
- **私有店铺数据回流**：官方产品定位是 ERP 原生 AI，明确基于 ERP 与业务数据分析；可判定有私有数据输入。是否把真实投放/销售结果自动反馈到下一轮“选品”排序，没有证据。
- **反馈是否改变下一轮选品**：商品诊断、销量归因、财务复盘和 VOC 能支持人工复盘后再选品，属于**经营闭环**；官方没有宣称模型自学习或自动改写下一轮候选，学习闭环未证实。
- **关键短摘**：官方写“选品时，高效收集竞品槽点，找准切入关键点”；“AI 在广告关键词报告、搜索词报告、ABA 报告等数据中……发现高价值流量机会”；“ERP 与 BI 数据同源、实时同步”（[赛狐 AI](https://www.sellfox.com/function/ai)）。

## 边界核验：领星、店小秘、数势不计入上面五家主样本

- **领星 ERP**：官方帮助页可核验的是“AI选词”，不是 AI 选品。流程是选广告商品和竞品 ASIN→从 ABA 热门搜索词、Listing 高频词挖词→质量分和 Top10 自然排名校验→把词加到广告组/词库；页面明确“添加到广告组”可直接开启投放。[帮助页](https://www.lingxing.com/help/article/AIKeyword)。这属于广告经营闭环/外部关键词数据，未找到实际“候选商品选品 Agent”。
- **店小秘**：官方帮助页有产品开发、数据采集和“采集插件 AI 一键发布”：从 1688 等货源采集，AI 填充/优化商品信息后发布；产品开发可调研商品、审核、生成 SKU，再发布到店铺。[产品刊登汇总](https://help.dianxiaomi.com/guide/guide/1355)，[产品开发](https://help.dianxiaomi.com/guide/guide/1083)。这是 AI 上架/铺货辅助，不是公开的市场选品 Agent，且未证明反馈学习。
- **数势科技**：官方/百度云商品页证明 SwiftAgent 是企业自然语言经营分析助手，可接企业多种数据源、指标和标签；另有 2022 年“智慧供应链平台”二手商品页宣称智能选品。但未找到面向跨境卖家的公开选品 Agent 产品页或跨境卖家端到端流程，因此不纳入主样本。[SwiftAgent 商品页](https://qianfanmarket.baidu.com/product/detail/5e8db74e-0aec-4ca9-824f-a48654076f91)。

## 横向结论（基于上述证据的推断）

1. 公开市场中最清晰的“外部市场更新”路线是 SellerSprite、Sorftime、LinkfoxAI：它们把 Amazon/多平台商品、关键词、趋势、评论、竞争数据交给 Agent/MCP，输出候选或研究结论。
2. “经营闭环”的私有数据入口包括 Linkfox 店铺经营助手、积加和赛狐：前者把 ERP 私有商品/店铺数据授权给数字员工、技能和长期任务；后者把评论、广告、销量、商品和利润分析嵌入 ERP。积加和赛狐的总览没有证明自动新品选品到采购/上架；Linkfox 已有选品到刊登文档，仍不能据此宣称销售结果自动反馈选品。
3. “学习闭环”标准应更严格：本次未找到任何主样本官方材料明确承诺“投放/销售结果自动回写，改变下一轮选品排序或模型”。候选沉淀、监控和人工复盘只能算经营流程闭环的证据，不能升级为模型学习闭环。
