# Pilot fixtures

这里预留给经过团队授权、可追溯的试点材料。仓库不提供伪造的供应商报价、市场返回、经营结果或核验回执，也不把 demo fixtures 当作团队业务数据。

真实试点材料应由管理员按团队的保密和留存约定另行提供，并在导入时标明来源定位、观察/统计窗口、版本和 `REAL` 或 `TEST`。没有真实材料时保持字段为空，或在页面记录待补证/未上市原因；不要用 `0`、示例链接或“已核验”占位。

字段口径与导入方式见 [团队试用交付指南](../../docs/pilot/team-trial-guide.md) 和 [首批字段、口径与数据源选择](../../docs/pilot/data-fields-and-sources.md)。
